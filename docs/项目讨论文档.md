# 国君 Alpha191 因子复现项目 · 复现交接文档

> 用途：与其他 AI / 同行交流本项目的完整背景，并使对方在本地的文件框架下复现全部交付物。
> 项目本地目录：`D:\quant\191\`（所有资料不放 C 盘）；数据源：本地 A 股量化数据库 `D:\stockdata`。
> 版本：v2（2026-10-08，交付完成后修订；v1 为开发期讨论稿）

## 1. 复现对象

- **报告**：国泰君安证券《基于短周期价量特征的多因子选股体系——数量化专题之九十三》，2017-06-15，分析师：李辰、刘富兵等。
- **内容**：191 个基于日频价量数据（OPEN/HIGH/LOW/CLOSE/VWAP/VOLUME/AMOUNT/RET + 基准指数）的短周期交易型阿尔法因子，即业界通称的 **"国泰君安 Alpha191"**。
- **报告原文核心结论**（2012.01–2017.04 样本内）：风格中性多因子策略相对中证 500 年化超额 50.2%、信息比率 4.67、最大回撤 5.9%、T+2 调仓、每期持股 50–60 只；因子体系对 T+1/T+2 预测最强，T+4 后 IR 降至 95% 显著性以下。

## 2. 本项目目标与最终结论（已交付）

**单因子层面的样本外检验**：191 个因子逐个在中证 500 股票池上检验报告发表后（2017-07）至 2026-09 的表现。

核心结论（详见研究报告）：

1. 整体显著性仍高（170/191 的 |t₅|>2）但强度腰斩：|RankIC₅| 均值 0.018，不足样本内一半，方向整体偏负（53% 为负）。
2. 量价相关性家族最稳健：Alpha83/99/62/16/90/42 样本外 ICIR₅ 0.33–0.44，行业中性化后进一步增强。
3. 波动率/成交额家族方向翻转（Alpha30/70/176 显著负 IC），反向使用即低波暴露。
4. 分年度呈"发表即衰减 → 2020–2021 低点 → 2022 起企稳回升"三阶段。
5. 因子间相关性大幅上升（|corr|<0.1 占比仅 31%，原报告 94%），全因子等权复合无意义；低相关强因子等权组合（多空夏普 Top5）夏普 1.96，优于任一单因子。
6. Alpha138 为数据缺口因子（公式窗口嵌套过深，多空序列与汇总指标未算出），已在看板中垫底隔离。

## 3. 检验口径（复现必须遵守的约定）

| 项目 | 口径 |
|---|---|
| 股票池 | 中证500 历史成分，PIT 月度区间表（含调出/退市股，消除幸存者偏差） |
| 区间 | 2016-01 取数暖机 → 2017-07-01 起评价 → 2026-09-30 |
| 价格 | 前复权；VWAP = AMOUNT/VOLUME ×（qfq_close/close）复权一致化 |
| 收益 | RET = 前复权收盘 `pct_change(fill_method=None)`，停牌不产生虚假收益 |
| 信号时点 | t 日收盘算因子，前瞻收益自 t 收盘起算（无未来函数） |
| IC | 日频 RankIC，h = 1/2/3/5/10；ICIR = 均值/标准差；t = ICIR×√N |
| 中性化 | 行业哑变量逐日截面回归取残差（规模因子缺失，见 §7 局限） |
| 多空 | 十分位等权多空，5 日非重叠调仓，未扣费 |
| 分段指标 | 近5年/近1年年化 ICIR（周频均值÷标准差×√52）；近3月趋势灯仅作预警 |

## 5. 公式来源与已知问题处理

- 报告表 6 经 OCR 提取出 **182 个**公式；OCR 缺失的 **Alpha51–58、Alpha149**（9 个）按 BigQuant 公开转录版补齐。
- 已知问题处理：Alpha30 无 SMB/HML 数据，改为仅对市场收益回归取残差（非原样）；Alpha51 按上移缺口占比方向；Alpha116 SEQUENCE(20)；Alpha131 DELAT→DELTA；Alpha159 HGIH→HIGH；Alpha143 递归变量 SELF 迭代（初值=1）；Alpha146 按字面化简；Alpha149 在 252 日窗口内仅用基准下跌日回归（min_periods=60）。
- 算子口径：RANK 截面升序归一化 (0,1]；TSRANK 末位排位 1..n；SMA 按通达信递归 `ewm(alpha=m/n, adjust=False)`；WMA 权重 0.9^i；DECAYLINEAR 权重 d..1；REGBETA 滚动斜率；REGRESI 窗口末点残差。

若复现正确，应得到（允许数据源差异带来的微小偏差）：

- 多空夏普>1 共 **10 个**，最高 Alpha105（1.35）

- 数据缺口：Alpha138（指标全空）；Alpha25 仅 2016 年年度柱缺失（热身期）

## 8. 与报告口径的差异（诚实声明）

1. 中性化仅行业维度：报告为行业+BARRA 十类风格正交；本地库无逐日市值字段，规模暴露未剥离（v2 可用 turn 推算流通市值补充）。
2. 主指标为 RankIC + 十分位多空，非报告的"风格中性因子收益率 f_k"，方向性结论一致、量纲不同。
3. 成分为月末快照（偏差 ≤ 约半个月，影响可忽略）；前复权（报告未披露）。
4. 未复现组合层（风格中性优化、T+2、成本罚函数）。
5. 多空与 IC 为毛收益，未扣费；5 日调仓年化换手约 50 倍，Top 因子扣费后夏普预计降 0.2–0.4。

## 9. 工程质量与陷阱

复现与看板开发中实际踩过的坑（NaN 污染排序、收益/净值混淆、日历不齐、HTML 闭合标签嵌套导致事件冒泡误删、canvas 尺寸参与排版逐次放大等）及对应校验手段，见研究报告**附录 2：复现工程陷阱清单**。看板页脚内置数据自检横幅（每次打开自动执行），复现后若自检变红即结果不可信。

## 10. 可与其他 AI 讨论的问题清单

1. Alpha30 的 SMB/HML 替代方案是否合理？是否有公开 A 股 FF 因子数据可用？
2. 规模中性的轻量做法（turn 推算流通市值 vs 直接拉总市值序列）？
3. Alpha146/149 等歧义公式的其他转录版本比对；Alpha138 缺口的修复（窗口嵌套拆解）。
4. 因子衰减度量：分年 IC vs 滚动 12 月 ICIR，哪种更适合判断"失效时点"？
5. 月频调仓口径扩展（h=20 IC + 20 日调仓多空）是否值得做？（用户暂缓，代号 D）
6. 短周期因子在 2023–2026 年量化监管（程序化交易新规、融券限制）后的结构性变化如何解读？
